# 不良品報告書作成アシスタント 設計書

## 1. システム概要

### 1.1 目的
- 不良品発生時の原因分析を深掘りし、再発防止につなげる
- 「何があったか」だけでなく「なぜ起きたか」を確実に記録
- 5Why分析を自然な対話で実施し、根本原因を特定
- 外国人スタッフでも高品質な報告書を作成可能に

### 1.2 対象不良
- 工程内不良（製造工程で発見された不良）
- 出荷後不良（顧客からのクレーム）
- 検査不良（検査工程で発見された不良）

## 3. 対話型分析機能

### 3.1 キャラクター設定

#### キャラクター1：**まさる課長（50代品質管理ベテラン）**
- 口調：「で、どんな不良やったがけ？」「原因はなんやろうね」
- 性格：冷静沈着、分析的、厳しいが優しい
- 役割：メイン分析者、5Why誘導

#### キャラクター2：**ゆみ主任（30代現場リーダー）**
- 口調：「それって、いつもと何が違っとったがけ？」
- 性格：現場感覚が鋭い、実務的
- 役割：現場視点での質問、具体性の確認

#### キャラクター3：**たかし技術者（40代設備保全担当）**
- 口調：「設備の調子はどうやった？」「データは見とるけ？」
- 性格：技術的、データ重視
- 役割：設備・技術面の深掘り

### 3.2 対話フロー

```
[Phase 1] 事象の把握（5分）
    ↓
[Phase 2] 状況の詳細確認（3分）
    ↓
[Phase 3] 5Why分析（8分）
    ↓
[Phase 4] 応急処置の確認（2分）
    ↓
[Phase 5] 恒久対策の検討（5分）
    ↓
[Phase 6] 水平展開の検討（2分）
```

### 3.3 質問内容詳細

#### Phase 1：事象の把握

```
まさる：「お疲れさまです。不良が出てしまったがやね。
        まず、どんな不良やったか教えてくれんけ？」

[ユーザー回答]

ゆみ：「なるほどのう。その不良、見た目でわかるもんけ？
       それとも検査せんとわからんもんけ？」

[ユーザー回答]

まさる：「で、何個くらい不良が出たがけ？
        全部やったがか、それとも一部け？」
```

**収集する情報：**
- 不良の具体的な現象（傷、割れ、寸法不良、機能不良など）
- 不良の発見方法（目視、検査、顧客発見）
- 不良の範囲（全数、一部、特定ロット）
- 不良率（可能であれば）

#### Phase 2：状況の詳細確認

```
たかし：「その不良が出た時の状況を教えてくれんけ？
        設備はいつも通り動いとったけ？」

[ユーザー回答]

ゆみ：「作業者さんは、いつもと違うことに気づいとらんかったけ？
      音とか、動きとか、材料の感じとか」

[ユーザー回答]

まさる：「その日、何か特別なことはなかったけ？
        材料が新しいロットやったとか、
        段取り替えの直後やったとか」
```

**収集する情報：**
- 4M変更点（Man: 作業者、Machine: 設備、Material: 材料、Method: 方法）
- 環境条件（温度、湿度、時間帯）
- 異常の予兆
- タイミング（いつから発生したか）

#### Phase 3：5Why分析（最重要）

```
まさる：「ほんなら、原因を一緒に考えていこうけ。
        なんで、その不良が出たと思う？」

[ユーザー回答：原因1]

まさる：「なるほどのう。ほんなら次の質問やけど、
        なんで[原因1]が起きたがやろうね？」

[ユーザー回答：原因2]

ゆみ：「うんうん。ほんなら、なんで[原因2]になったがけ？
      何か防げんかったもんけ？」

[ユーザー回答：原因3]

たかし：「ふむふむ。で、なんで[原因3]の状態やったがけ？
        点検とかはしとったがけ？」

[ユーザー回答：原因4]

まさる：「最後の質問やけど、なんで[原因4]が
        見逃されとったがやろうか？」

[ユーザー回答：根本原因]

まさる：「ありがとうございます。今のお話で、
        根本的な原因が見えてきたがやね」
```

**5Why分析の制御ロジック：**

```python
why_count = 0
root_cause_found = False

while why_count < 5 and not root_cause_found:
    why_count += 1
    ask_why_question(previous_answer)
    
    # 根本原因判定
    if has_keyword(answer, ["ルール", "仕組み", "教育", "チェック体制"]):
        root_cause_found = True
        
    # 浅い回答の検出
    if len(answer) < 20:
        ask_for_more_detail()
        
    # 堂々巡りの検出
    if answer_similar_to_previous():
        change_perspective()
```

#### Phase 4：応急処置の確認

```
ゆみ：「で、今はどんな対応しとるがけ？
      出荷は止めとるけ？」

[ユーザー回答]

まさる：「良品と不良品の選別はできとるけ？
        既に出荷したものはないけ？」

[ユーザー回答]

たかし：「設備や作業方法、何か変えたもんはあるけ？」
```

**収集する情報：**
- 実施済みの応急処置
- 流出防止策
- 在庫・出荷品の処置
- 暫定的な作業変更

#### Phase 5：恒久対策の検討

```
まさる：「ほんなら、同じことが起きんようにするには、
        どうしたらいいと思う？」

[ユーザー回答]

たかし：「その対策、いつ頃までにできそうけ？
        予算とか、設備改造とか必要け？」

[ユーザー回答]

ゆみ：「対策したあと、ちゃんと効果があったか
      どうやって確認するがけ？」

[ユーザー回答]

まさる：「担当者は誰になるがけ？
        一人でできるもんけ、それとも
        関係部署と協力が必要け？」
```

**収集する情報：**
- 恒久対策の内容
- 実施予定日
- 担当部署・担当者
- 必要なリソース（予算、工数、承認）
- 効果確認方法

#### Phase 6：水平展開の検討

```
まさる：「最後の質問やけど、この不良、
        他のラインや製品でも起きる可能性あるけ？」

[ユーザー回答]

ゆみ：「似たような設備や工程、他にもあるがやね。
      そっちもチェックした方がよさそうやね」

[ユーザー回答]

たかし：「他部署にも共有した方がいい情報あるけ？」
```

**収集する情報：**
- 水平展開の必要性
- 対象ライン・製品
- 他部署への情報共有

### 4.2 文章生成ルール

#### 4.2.1 基本方針
- **事実ベース**：推測や憶測を排除
- **具体的**：「少し」「かなり」などの曖昧表現を避け、数値化
- **時系列明確**：いつ、何が起きたかを明確に
- **5W1H**：誰が、いつ、どこで、何を、なぜ、どのように

#### 4.2.2 NGワード・NG表現の自動修正

| NG表現 | 理由 | 修正例 |
|--------|------|--------|
| 「多分〜」「〜かもしれない」 | 推測 | 削除または「要確認」と明記 |
| 「いつも」「時々」 | 曖昧 | 「過去3回中2回」など具体化 |
| 「ちょっと」「少し」 | 定量性なし | 「5mm」「10%」など数値化 |
| 「注意不足」 | 原因分析不足 | より深い原因を追記 |
| 「今後気をつける」 | 対策不明確 | 具体的な対策に変更 |

#### 4.2.3 品質レベル自動チェック

```
[チェック項目]
□ 5Why分析が3回以上実施されているか
□ 根本原因が「人のせい」だけになっていないか
□ 恒久対策に期限と担当者が設定されているか
□ 効果確認方法が具体的に記載されているか
□ 写真が添付されているか（外観不良の場合）

品質スコア：[X] / 5
※スコアが3以下の場合は警告表示
```

## 16. 詳細機能仕様

### 16.1 AI対話エンジン詳細

#### 16.1.1 プロンプト設計

**システムプロンプト（まさる課長の例）**

```
あなたは富山県の製造メーカーで50年働くベテラン品質管理課長「まさる」です。
以下の特徴で対話してください：

【キャラクター設定】
- 年齢：55歳
- 経験：品質管理一筋30年
- 性格：温厚だが厳格、論理的思考
- 口調：富山弁、丁寧語と方言のミックス

【富山弁の例】
- 「〜がけ？」（〜ですか？）
- 「〜やね」（〜ですね）
- 「そんがん」（そういう）
- 「ほんなら」（それでは）
- 「なるほどのう」（なるほど）

【対話の目的】
不良品報告書を作成するため、ユーザーから以下の情報を引き出す：
1. 不良の具体的な現象
2. 発生状況の詳細
3. 5Why分析による根本原因
4. 応急処置の内容
5. 恒久対策の計画
6. 水平展開の必要性

【対話ルール】
1. 一度に1つの質問のみ
2. ユーザーの回答が短い場合（20文字以下）は追加質問で深掘り
3. 5Why分析では必ず「なぜ」を5回繰り返す
4. 根本原因が「人のミス」だけで終わらないよう誘導
5. 具体的な数値や事実を引き出す
6. 共感と励ましを忘れずに

【禁止事項】
- ユーザーを責めるような言い方
- 専門用語の連発（必要な場合は説明を添える）
- 長すぎる質問（3文以内）
- 答えを誘導しすぎる質問

【現在のPhase】
Phase 3: 5Why分析
Why回数: 2回目

【これまでの情報】
- 不良内容: 塗装ムラ
- なぜ1: スプレーガンの圧力が不安定
- なぜ2: [ここから質問]

次の質問を富山弁で自然に投げかけてください。
```

#### 16.1.2 対話制御ロジック

```python
class DialogueController:
    def __init__(self):
        self.phase = 1  # 1-6のPhase
        self.why_count = 0  # 5Why分析のカウント
        self.collected_data = {}  # 収集したデータ
        self.question_count = 0  # 総質問数
        
    def get_next_question(self, user_response):
        """次の質問を生成"""
        
        # 回答の品質チェック
        if len(user_response) < 20:
            return self.ask_for_detail()
        
        # Phaseごとの処理
        if self.phase == 1:  # 事象把握
            return self.phase1_questions()
        elif self.phase == 3:  # 5Why分析
            return self.phase3_why_analysis()
        # ... 他のPhase
        
    def phase3_why_analysis(self):
        """5Why分析の質問生成"""
        
        if self.why_count >= 5:
            # 根本原因判定
            if self.is_root_cause():
                return self.move_to_next_phase()
            else:
                return self.suggest_deeper_analysis()
        
        self.why_count += 1
        
        # 前回の回答を取得
        previous_cause = self.collected_data[f'why{self.why_count-1}']
        
        # 質問文を生成
        prompt = f"""
        前回のユーザーの回答: {previous_cause}
        
        この原因についてさらに深掘りする質問を、
        富山弁で自然に投げかけてください。
        
        Why{self.why_count}回目の質問です。
        """
        
        return self.ai_generate(prompt)
    
    def is_root_cause(self):
        """根本原因に到達したか判定"""
        
        last_cause = self.collected_data[f'why{self.why_count}']
        
        # 根本原因のキーワード
        root_keywords = [
            'ルール', '仕組み', '体制', 'チェック',
            '教育', '訓練', 'マニュアル', '基準',
            '確認方法', '管理方法'
        ]
        
        # キーワードマッチング
        for keyword in root_keywords:
            if keyword in last_cause:
                return True
        
        # AIで判定
        prompt = f"""
        以下の原因分析が根本原因に到達しているか判定してください。
        
        Why1: {self.collected_data['why1']}
        Why2: {self.collected_data['why2']}
        ...
        Why{self.why_count}: {last_cause}
        
        根本原因の条件:
        - 単なる現象や症状ではない
        - 人のせいだけで終わっていない
        - 仕組みや体制の問題に言及している
        - 対策を講じれば再発防止できる
        
        判定: YES / NO
        理由:
        """
        
        return self.ai_judge(prompt)
    
    def ask_for_detail(self):
        """詳細を聞く質問"""
        
        variations = [
            "もうちょっと詳しく教えてくれんけ？",
            "具体的にはどんな感じやったがけ？",
            "そこ、もう少し詳しく聞かせてくれるけ？",
            "なるほどのう。で、どんな状況やったがけ？"
        ]
        
        return random.choice(variations)
    
    def detect_circular_reasoning(self):
        """堂々巡り（同じ回答の繰り返し）を検出"""
        
        recent_answers = [
            self.collected_data.get(f'why{i}') 
            for i in range(max(1, self.why_count-2), self.why_count+1)
        ]
        
        # 類似度チェック（簡易版）
        for i, ans1 in enumerate(recent_answers):
            for ans2 in recent_answers[i+1:]:
                similarity = self.calculate_similarity(ans1, ans2)
                if similarity > 0.8:
                    return True
        
        return False
    
    def change_perspective(self):
        """視点を変える質問"""
        
        return """
        ちょっと違う角度から考えてみようけ。
        この問題、他の人から見たらどう見えるやろうね？
        例えば、作業者さんの立場やったら？
        それとも、設備の立場やったら？
        """
```

class ReportGenerator:
    """対話データから報告書を生成"""
    
    def generate_report(self, dialogue_data):
        """完全な報告書を生成"""
        
        report = {
            'basic_info': self.generate_basic_info(dialogue_data),
            'defect_content': self.generate_defect_content(dialogue_data),

            'permanent_action': self.generate_permanent_action(dialogue_data),
            'horizontal_deployment': self.generate_horizontal_deployment(dialogue_data)
        }
        
        return self.format_report(report)
    
    def generate_defect_content(self, dialogue_data):
        """不良内容セクションの生成"""
        
        # 対話から抽出したデータ
        defect_info = dialogue_data['defect_info']
        
        prompt = f"""
        以下の情報から、不良内容セクションを自然な日本語で記述してください。
        
        【条件】
        - 事実のみを記載（推測を含めない）
        - 時系列で整理
        - 具体的な数値を含める
        - 200-300文字程度
        - です・ます調
        
        【情報】
        不良の種類: {defect_info['type']}
        具体的症状: {defect_info['symptom']}
        発見経緯: {defect_info['discovery']}
        発生範囲: {defect_info['scope']}
        不良数: {defect_info['quantity']}
        不良率: {defect_info['rate']}
        
        【生成例】
        塗装工程において、製品表面に塗装ムラが発生しました。
        不良は2025年10月12日14:30に目視検査で発見され、
        特に午後の生産分（14:00以降）に集中して発生していました。
        不良数は50個／生産数330個で、不良率は約15%に達しました。
        塗装ムラは主に製品の右側面に発生しており、
        厚みが不均一になっている状態でした。
        """
        
        return self.ai_generate(prompt)
    
    def generate_5why(self, dialogue_data):
        """5Why分析セクションの生成"""
        
        why_data = dialogue_data['why_analysis']
        
        # 各Whyを整形
        formatted_whys = []
        for i in range(1, 6):
            if f'why{i}' in why_data:
                formatted_whys.append({
                    'question': self.format_why_question(i, why_data),
                    'answer': self.improve_answer(why_data[f'why{i}'])
                })
        
        # 根本原因の分類
        root_cause_category = self.categorize_root_cause(
            why_data['why5']
        )
        
        return {
            'why_chain': formatted_whys,
            'root_cause': why_data['why5'],
            'category': root_cause_category,
            'summary': self.summarize_root_cause(why_data)
        }
    
    def improve_answer(self, answer):
        """回答文を改善（曖昧表現の除去など）"""
        
        # NGワードの検出と修正
        ng_patterns = {
            r'多分|恐らく|かもしれない': '[要確認]',
            r'いつも|時々|たまに': '[頻度を具体化]',
            r'ちょっと|少し|結構': '[程度を数値化]',
            r'注意不足|気の緩み': '[より具体的な原因が必要]'
        }
        
        improved = answer
        for pattern, replacement in ng_patterns.items():
            if re.search(pattern, improved):
                # AIで改善提案
                improved = self.suggest_improvement(improved, pattern)
        
        return improved
    
    def categorize_root_cause(self, root_cause):
        """根本原因を分類"""
        
        categories = {
            '設備': ['設備', '機械', '装置', '機器'],
            '作業方法': ['手順', '方法', '作業', 'やり方'],
            '管理体制': ['ルール', '仕組み', '体制', 'チェック', '確認'],
            '教育': ['教育', '訓練', '指導', '知識'],
            '材料': ['材料', '原料', '部品']
        }
        
        for category, keywords in categories.items():
            for keyword in keywords:
                if keyword in root_cause:
                    return category
        
        return 'その他'

#### 16.2.2 品質スコアリング

```python
class QualityScorer:
    """報告書の品質を評価"""
    
    def calculate_score(self, report_data):
        """品質スコアを計算（5点満点）"""
        
        score = 0
        feedback = []
        
        # 1. 5Why分析の深さ（1点）
        why_score = self.evaluate_why_depth(report_data['why_analysis'])
        score += why_score
        if why_score < 1:
            feedback.append("5Why分析がもう少し深いと良いです")
        
        # 2. 根本原因の質（1点）
        root_score = self.evaluate_root_cause(
            report_data['why_analysis']['why5']
        )
        score += root_score
        if root_score < 1:
            feedback.append("根本原因が表面的です。仕組みの問題まで掘り下げましょう")
        
        # 3. 具体性（1点）
        concrete_score = self.evaluate_concreteness(report_data)
        score += concrete_score
        if concrete_score < 1:
            feedback.append("数値データや具体例をもっと含めましょう")
        
        # 4. 対策の実効性（1点）
        action_score = self.evaluate_actions(
            report_data['permanent_action']
        )
        score += action_score
        if action_score < 1:
            feedback.append("恒久対策がより具体的だと良いです")
        
        # 5. 完成度（1点）
        complete_score = self.evaluate_completeness(report_data)
        score += complete_score
        if complete_score < 1:
            feedback.append("一部のセクションに情報不足があります")
        
        return {
            'total_score': score,
            'max_score': 5,
            'rating': self.get_rating(score),
            'feedback': feedback,
            'details': {
                'why_depth': why_score,
                'root_cause_quality': root_score,
                'concreteness': concrete_score,
                'action_effectiveness': action_score,
                'completeness': complete_score
            }
        }
    
    def evaluate_why_depth(self, why_analysis):
        """5Why分析の深さを評価"""
        
        # Why5まで到達しているか
        if 'why5' not in why_analysis:
            return 0.3
        
        # 各Whyの文字数（浅い回答は短い傾向）
        avg_length = sum(
            len(why_analysis[f'why{i}']) 
            for i in range(1, 6) if f'why{i}' in why_analysis
        ) / 5
        
        if avg_length < 20:
            return 0.5
        elif avg_length < 40:
            return 0.7
        else:
            return 1.0
    
    def evaluate_root_cause(self, root_cause):
        """根本原因の質を評価"""
        
        # NGパターン（人のせいで終わっている）
        ng_patterns = [
            '注意不足', '確認ミス', '見落とし',
            '気の緩み', '慣れ', '油断'
        ]
        
        for pattern in ng_patterns:
            if pattern in root_cause and len(root_cause) < 50:
                return 0.3  # 人のせいだけで終わっている
        
        # OKパターン（仕組みの問題）
        ok_patterns = [
            'ルール', '仕組み', '体制', 'チェック',
            'マニュアル', '基準', '教育', '手順'
        ]
        
        for pattern in ok_patterns:
            if pattern in root_cause:
                return 1.0
        
        return 0.6  # 中間
    
    def evaluate_concreteness(self, report_data):
        """具体性を評価（数値データの有無など）"""
        
        score = 0.0
        
        # 数値データの存在確認
        number_pattern = r'\d+\.?\d*(%|個|mm|℃|MPa|秒|分)'
        
        sections_to_check = [
            'defect_content',
            'situation',
            'permanent_action'
        ]
        
        for section in sections_to_check:
            text = str(report_data.get(section, ''))
            if re.search(number_pattern, text):
                score += 0.33
        
        return min(score, 1.0)
    
    def get_rating(self, score):
        """スコアから評価を返す"""
        
        if score >= 4.5:
            return "優良"
        elif score >= 3.5:
            return "良好"
        elif score >= 2.5:
            return "要改善"
        else:
            return "不十分"
```

class PhotoManager:

        )
        thumbnail_url = self.upload_to_s3(
            thumbnail,
            f"{report_id}/photo_{photo_index}_thumb.jpg"
        )
        
        # メタデータ保存
        metadata = {
            'report_id': report_id,
            'photo_index': photo_index,
            'original_url': original_url,
            'thumbnail_url': thumbnail_url,
            'uploaded_at': datetime.now(),
            'file_size': len(file),
            'dimensions': self.get_dimensions(file),
            'exif_data': self.extract_exif(file)
        }
        
        self.save_metadata(metadata)
        
        return metadata
    
    def add_watermark(self, image, report_id):
        """ウォーターマークを追加"""
        
        from PIL import Image, ImageDraw, ImageFont
        
        img = Image.open(image)
        draw = ImageDraw.Draw(img)
        
        # ウォーターマークテキスト
        watermark_text = f"社外秘 {report_id}"
        
        # 右下に配置
        width, height = img.size
        font = ImageFont.truetype("arial.ttf", 20)
        text_width, text_height = draw.textsize(watermark_text, font)
        
        position = (width - text_width - 10, height - text_height - 10)
        draw.text(position, watermark_text, fill=(255, 0, 0), font=font)
        
        return img
```

### 17.2 ビュー定義

#### ビュー1: v_dashboard_summary（ダッシュボード用サマリ）

```sql
CREATE VIEW v_dashboard_summary AS
SELECT 
    DATE_TRUNC('month', created_at) as month,
    COUNT(*) as total_reports,
    COUNT(*) FILTER (WHERE status = 'completed') as completed_reports,
    COUNT(*) FILTER (WHERE is_customer_complaint = TRUE) as customer_complaints,
    AVG(defect_rate) as avg_defect_rate,
    AVG(quality_score) as avg_quality_score
FROM defect_reports
WHERE created_at >= CURRENT_DATE - INTERVAL '12 months'
GROUP BY DATE_TRUNC('month', created_at)
ORDER BY month DESC;
```

#### ビュー2: v_pending_approvals（承認待ち一覧）

```sql
CREATE VIEW v_pending_approvals AS
SELECT 
    dr.report_id,
    dr.report_number,
    dr.product_name,
    dr.defect_type,
    dr.reporter_name,
    dr.submitted_at,
    dr.status,
    dr.approval_flow,
    CURRENT_TIMESTAMP - dr.submitted_at as waiting_duration
FROM defect_reports dr
WHERE dr.status IN ('submitted', 'approved')  -- 承認フロー途中

#### ビュー3: v_root_cause_ranking（根本原因ランキング）

```sql
CREATE VIEW v_root_cause_ranking AS
SELECT 
    root_cause_category,
    COUNT(*) as occurrence_count,
    ROUND(COUNT(*) * 100.0 / SUM(COUNT(*)) OVER (), 2) as percentage,
    AVG(defect_rate) as avg_defect_rate,
    STRING_AGG(DISTINCT product_name, ', ' ORDER BY product_name) as affected_products
FROM defect_reports
WHERE status = 'completed'
  AND created_at >= CURRENT_DATE - INTERVAL '6 months'
GROUP BY root_cause_category
ORDER BY occurrence_count DESC;
```

# JWT（JSON Web Token）ベースの認証

class AuthService:
    def login(self, employee_id, password):
        """ログイン処理"""
        
        # 社員マスタで認証（SSO連携も可）
        user = self.authenticate_user(employee_id, password)
        
        if not user:
            raise AuthenticationError("認証に失敗しました")
        
        # JWTトークン生成
        payload = {
            'user_id': user.employee_id,
            'name': user.name,
            'department': user.department,
            'role': user.role,  # general/leader/manager/qa/admin
            'exp': datetime.utcnow() + timedelta(hours=8)
        }
        
        token = jwt.encode(payload, SECRET_KEY, algorithm='HS256')
        
        # リフレッシュトークン生成
        refresh_token = self.generate_refresh_token(user.employee_id)
        
        return {
            'access_token': token,
            'refresh_token': refresh_token,
            'expires_in': 28800  # 8時間
        }
```

#### 19.1.2 権限管理

```python
# ロールベースアクセス制御（RBAC）

class Permission:
    ROLES = {
        'general': {  # 一般作業者
            'create_report': True,
            'edit_own_report': True,
            'view_own_report': True,
            'edit_others_report': False,
            'view_others_report': False,
            'approve_report': False,
            'delete_report': False,
            'view_analytics': False
        },
        'leader': {  # 現場リーダー
            'create_report': True,
            'edit_own_report': True,
            'view_own_report': True,
            'edit_others_report': True,  # 自部署のみ
            'view_others_report': True,  # 自部署のみ
            'approve_report': True,
            'delete_report': False,
            'view_analytics': True  # 自部署のみ
        },
        'manager': {  # 課長・部長
            'create_report': True,
            'edit_own_report': True,
            'view_own_report': True,
            'edit_others_report': True,  # 自部署のみ
            'view_others_report': True,  # 全社
            'approve_report': True,
            'delete_report': True,
            'view_analytics': True  # 全社
        },
        'qa': {  # 品質管理部門
            'create_report': True,
            'edit_own_report': True,
            'view_own_report': True,
            'edit_others_report': True,  # 全社
            'view_others_report': True,  # 全社
            'approve_report': True,
            'delete_report': True,
            'view_analytics': True,  # 全社
            'manage_masters': True
        },
        'admin': {  # システム管理者
            'all': True
        }
    }
    
    @staticmethod
    def check_permission(user_role, action, target_report=None):
        """権限チェック"""
        
        if user_role == 'admin':
            return True
        
        permissions = Permission.ROLES.get(user_role, {})
        
        # 基本権限チェック
        if not permissions.get(action, False):
            return False
        
        # 部署による制限チェック
        if target_report and action in ['edit_others_report', 'view_others_report']:
            if user_role == 'leader':
                # リーダーは自部署のみ
                return target_report.department == user.department
        
        return True
```
